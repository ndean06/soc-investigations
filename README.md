# SOC Investigation

This repository contains **SOC-style incident investigations**.  
Each case follows a similar workflow: detection, timeline creation, scoping, findings, and client-facing recommendations.

> **Note:** All investigations in this repository are **simulated scenarios** completed for practice, learning, and skill development.  
> The purpose of this repository is to improve incident response understanding, demonstrate investigative methodology, and share knowledge.

## How to Use This Repository

Each incident folder includes:
- `README.md` – High-level incident overview
- `Incident-Report.md` – Client-facing report
- `Walkthrough.md` – Analyst decision-making and investigation process
- `Timeline.csv` – Event timeline
- `IOCs.csv` – Indicators of Compromise
- `Scoping.md` – Scope assessment and containment confirmation
- `queries/` – Advanced Hunting queries used during investigation

Start with the incident `README.md`, then review the report or walkthrough depending on interest level.
